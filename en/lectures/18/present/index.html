Lecture 18

The complete solution set

One solution of a consistent system determines the location of its whole solution set. The system with zero right sides determines the allowed differences between solutions. We construct a basis for those differences from the free variables and use it to describe every solution without repetition. The dimension convention is stated in terms of the cited intrinsic pivot count.

Uses.

  • Summary 12: Componentwise operations define real vectors, linear combinations and independence. Standard coordinate entries are unique.

  • Summary 13: For real columns, two independent directions describe a plane through the origin.

  • Summary 15: Complex scalars obey the arithmetic laws used in component computations.

  • Summary 17: Matrix–column action records a linear system. Row operations preserve solutions and expose all free variables. Route-independent pivot counts use the cited uniqueness of reduced form.

18.1 Homogeneous systems and linear subspaces

Keep K=RK=\RK=R or K=CK=\CK=C, and let AAA have mmm rows and nnn columns, with m,n≥1m,n\geq1m,n≥1. Column addition and scalar multiplication in KnK^nKn are defined entrywise, just as for the real vectors of Lecture 12. Write 0k0_k0k​ for the column of kkk zero entries. The coefficient action is linear: for u,v∈Knu,v\in K^nu,v∈Kn and a,b∈Ka,b\in Ka,b∈K, A(au+bv)=aAu+bAv.\begin{equation} \label{eq:18:linearity} A(au+bv)=aAu+bAv. \end{equation}A(au+bv)=aAu+bAv.(18.2) For each row index i=1,…,mi=1,\ldots,mi=1,…,m, its left entry is ∑j=1naij(auj+bvj)=a∑j=1naijuj+b∑j=1naijvj,\sum_{j=1}^n a_{ij}(au_j+bv_j) =a\sum_{j=1}^n a_{ij}u_j+b\sum_{j=1}^n a_{ij}v_j,j=1∑n​aij​(auj​+bvj​)=aj=1∑n​aij​uj​+bj=1∑n​aij​vj​, which is the right entry. A subset V⊆KnV\subseteq K^nV⊆Kn is a linear subspace if it contains 0n0_n0n​ and is closed under addition and scalar multiplication. The null space is such a subspace. Indeed, if Au=Av=0mAu=Av=0_mAu=Av=0m​, linearity gives A(u+v)=0mA(u+v)=0_mA(u+v)=0m​ and A(cu)=0mA(cu)=0_mA(cu)=0m​ for every c∈Kc\in Kc∈K. 18.2 Particular plus homogeneous

A particular solution is one fixed column ppp satisfying Ap=bAp=bAp=b. Such a column is available only if the system is consistent. For a linear subspace V⊆KnV\subseteq K^nV⊆Kn, its translate by p∈Knp\in K^np∈Kn is p+V={p+h:h∈V}.p+V=\{p+h:h\in V\}.p+V={p+h:h∈V}. A set of this form is an affine subspace. It contains ppp but need not contain the zero column.

Two solutions therefore differ by a homogeneous solution. Choosing another particular solution gives the same set, since the theorem identifies either translate with the solutions of the same system. If b≠0mb\ne0_mb=0m​ and the system is consistent, its solution set is affine and is not a linear subspace: A0n=0m≠bA0_n=0_m\ne bA0n​=0m​=b excludes the zero column. 18.3 Span, independence and coordinates

For columns v1,…,vk∈Knv_1,\ldots,v_k\in K^nv1​,…,vk​∈Kn, their span is the set of all linear combinations span⁡(v1,…,vk)={∑j=1kcjvj:cj∈K}.\operatorname{span}(v_1,\ldots,v_k) =\left\{\sum_{j=1}^k c_jv_j:c_j\in K\right\}.span(v1​,…,vk​)={j=1∑k​cj​vj​:cj​∈K}. A span is a linear subspace. The zero choice of all coefficients gives 0n0_n0n​. Adding two combinations adds their coefficients, and multiplying by a scalar multiplies each coefficient. Thus both closure properties hold. The span of the empty family is defined to be {0n}\{0_n\}{0n​}, using the empty sum.

The family is linearly independent over KKK if ∑j=1kcjvj=0n⟹c1=⋯=ck=0.\sum_{j=1}^k c_jv_j=0_n\quad\Longrightarrow\quad c_1=\cdots=c_k=0.j=1∑k​cj​vj​=0n​⟹c1​=⋯=ck​=0. Otherwise it is linearly dependent. These extend the real definitions of Lecture 12 to the chosen column scalars. The empty family is independent, since there is no nonzero coefficient choice. An ordered basis of a subspace VVV is a finite ordered independent family whose span is VVV. We use the word basis with this ordering understood. The empty family is a basis of {0n}\{0_n\}{0n​}.

Every column in a subspace with basis v1,…,vkv_1,\ldots,v_kv1​,…,vk​ has a unique expression x=∑j=1kcjvjx=\sum_{j=1}^k c_jv_jx=∑j=1k​cj​vj​. Existence follows from spanning. For uniqueness, subtract two expressions to get ∑j(cj−dj)vj=0n\sum_j(c_j-d_j)v_j=0_n∑j​(cj​−dj​)vj​=0n​. Independence forces cj=djc_j=d_jcj​=dj​ for each jjj. The coefficients in that order are the coordinates in the basis. With an empty basis, the zero column has the single empty representation. The standard coordinate columns form a basis of KnK^nKn by the same component argument as in Lecture 12.

To test membership in a span, form the coefficient matrix whose columns are v1,…,vkv_1,\ldots,v_kv1​,…,vk​ and solve for the unknown coefficients cjc_jcj​. To test independence, set the target column to zero. Independence means that this homogeneous coefficient system has only its zero solution. These are elimination tests from Lecture 17.

18.4 The basis supplied by free variables

In Lecture 17, the consistent family at λ=μ=0\lambda=\mu=0λ=μ=0 was x(t)=(−960)+t(7−31).x(t)=\begin{pmatrix}-9\\6\\0\end{pmatrix} +t\begin{pmatrix}7\\-3\\1\end{pmatrix}.x(t)=​−960​​+t​7−31​​. Theorem 18.2 (Null-space basis from free variables). The special columns h1,…,hkh_1,\ldots,h_kh1​,…,hk​ form a basis of ker⁡A\ker AkerA. Proof. First suppose k≥1k\geq1k≥1. A relation ∑jcjhj=0n\sum_j c_jh_j=0_n∑j​cj​hj​=0n​ has value cℓc_\ellcℓ​ in free position fℓf_\ellfℓ​, by the way the special columns were assigned. Thus cℓ=0c_\ell=0cℓ​=0 for each ℓ\ellℓ, proving independence.

For a homogeneous solution hhh, choose tj=hfjt_j=h_{f_j}tj​=hfj​​. The combination ∑jtjhj\sum_jt_jh_j∑j​tj​hj​ is homogeneous by linearity and has exactly the same free coordinates as hhh. If k=0k=0k=0, there are no free variables, and the homogeneous system has only 0n0_n0n​ by the same consistency theorem. The empty independent family spans this set, proving the final case. 

The construction proves a basis for each null space without requiring a basis-existence theorem for arbitrary subspaces. There are at most mmm coefficient pivots in any reduction. Consequently, if n>mn>mn>m, there is a free column and a nonzero homogeneous solution: assign 1 in that free coordinate and 0 in the others. For nonzero right sides, consistency is still a separate condition. The last task on Sheet 17 gives an explicit inconsistent example with more unknowns than equations.

Rank and the dimension convention

The cited pivot-count invariance in Theorem 17.4 makes the number of coefficient pivots independent of the chosen reduction. This number is the rank of AAA, denoted by rank⁡A\rank ArankA. For null spaces, the dimension convention used here is dim⁡ker⁡A=n−rank⁡A.\begin{equation} \label{eq:18:dimension} \dim\ker A=n-\rank A. \end{equation}dimkerA=n−rankA.(18.3) The constructed free-variable basis has exactly that many columns. The count’s independence from the reduction route uses the cited result; the basis construction and its independence and spanning proofs above hold directly for any chosen reduction. This convention specifies dimension for null spaces through elimination.

Summary

  • Equations (18.1) and (18.2): the homogeneous solution set is a linear subspace, by linearity of the coefficient action.
  • Theorem 18.1: a consistent system has solution set p+ker⁡Ap+\ker Ap+kerA for any particular solution ppp. It is unique exactly when ker⁡A={0n}\ker A=\{0_n\}kerA={0n​}.
  • An ordered basis is independent and spans its subspace. Its coordinate coefficients are unique. Span and independence tests are coefficient systems.
  • Theorem 18.2: one special homogeneous solution for each free variable gives a basis. The empty family handles a zero null space.
  • Equation (18.3): rank and the null-space dimension convention use the cited route-independent pivot count from Lecture 17. For an actual reduction with rrr pivots, the proved basis has n−rn-rn−r columns.
